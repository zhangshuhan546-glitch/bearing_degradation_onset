轴承退化起点检测和更换成本比较

-基于XJTU-SY 轴承数据集（西安交通大学），工况1：转速35Hz、径向力12kN,共五个轴承
-每分钟采样一次，每次1.28s,采样频率为25.6kHz,每次32768个点
-只采用水平方向振动信号
- 原始数据请从作者仓库下载：https://github.com/WangBiaoXJTU/xjtu-sy-bearing-datasets
- 引用：Wang B, Lei Y, et al. IEEE Transactions on Reliability, 2020

 方法
 -1.对每个采样文件提取3个特征，RMS（整体振动情况），p2p（最大跨度），kurt（是否突然出现尖峰冲击）
 -2.退化起点为前20分钟的均值+3*标准差为警戒线，RMS连续3次超过警戒线的点为退化起点（连续三次为了区分一次偶然波动带来的误差）
 -3.成本模型（假设）：失效一次损失100，提前更换没浪费一分钟损失1

 主要发现
 -五个轴承的寿命分别是123、161、158、122、52分钟，退化起点分别是70、37、59、88、30分钟，起点所占寿命约23%到72%
 -基线长度取20到50分钟，连续点取3到5，Bearing_1_1的起点在69到74之间，结果较稳定
 -Bearing1_4在原尺寸图中几乎看不到征兆；去掉最后三分钟放大后，约80分钟起RMS和峭度出现变化
 -三种策略成本对比
   _坏了再换：100
   _定期更换：最优T=120时为36.8，但对样本敏感度高，T=130时上升至71.8
   _检测到退化后再运行D分钟后更换，最优D=20时为46.4

局限和下一步
-只有5个轴承，成本数字为假设值，需用真实场景核实
-定期更换的最优T是在同一批样本中选出的，对样本敏感
-只用水平方向，只用RMS判断起点，只有一种工况，后续会完善
-Bearing_1_5的寿命为52，退化起点为20，占总寿命的38%，可能混入早期退化
-检测到退化后再换的策略受限于退化后的最短剩余寿命(Bearing_1_5约22分钟)
-下一步：预测剩余寿命

如何运行
所有脚本在 `code` 文件夹内运行，依赖：pandas、numpy、scipy、matplotlib。
- 只复现结果和图：直接运行 `step4`、`step5`、`step7`、`step7_b`、`step8`、`step9`（读取 `features` 文件夹里的特征表，不需要原始数据）
- 从原始数据重新提取特征：先下载数据，修改脚本开头的 `DATA_ROOT`，再运行 `step1` 到 `step3`、`step6`
